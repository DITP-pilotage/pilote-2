# 003. Migration vers les certificats ACME sur Scalingo avec Certigna

Date : 2025-01-11

## Contexte

Notre infrastructure est déployée sur la plateforme Scalingo (`*.osc-fr1.scalingo.io` et `*.osc-secnum-fr1.scalingo.io`) et utilise actuellement des certificats RGS* Certigna avec renouvellement manuel pour sécuriser les connexions HTTPS.

Le contexte réglementaire évolue :
- Les certificats RGS* ont une durée de vie qui se raccourcit (actuellement 3 mois)
- À terme, ces certificats ne seront valables qu'un jour
- Cette évolution rend la gestion manuelle des certificats impraticable et risquée

Forces en présence :
- **Sécurité** : Nécessité de maintenir des connexions HTTPS sécurisées et conformes
- **Réglementaire** : Obligation de respecter les standards RGS* pour les applications gouvernementales
- **Opérationnelle** : Éviter les interruptions de service dues à l'expiration de certificats
- **Technique** : Certigna propose maintenant des "Certificat SSL ACME" RGS*
- **Conformité** : Maintien des certifications RGS* nécessaires pour nos applications
- **Automatisation** : Passage du renouvellement manuel vers le protocole ACME automatisé
- **Maintenance** : Réduire la charge opérationnelle tout en conservant la conformité

**Contrainte technique** : Scalingo ne supporte que Let's Encrypt pour l'ACME automatique, nous devrons importer manuellement les certificats Certigna ACME.

## Décision

Nous migrons vers les certificats "Certigna SSL ACME" tout en conservant la conformité RGS* requise pour nos applications gouvernementales.

Cette migration comprend :
1. **Passage aux certificats Certigna SSL ACME** avec renouvellement automatisé côté Certigna
2. **Import des certificats** dans Scalingo via CLI ou dashboard
3. **Mise en place d'un processus de renouvellement** semi-automatique
4. **Conservation de la conformité RGS*** nécessaire pour notre contexte réglementaire

Le processus technique sera :
```bash
# 1. Commande des certificats Certigna SSL ACME via leur interface
# 2. Récupération des certificats générés automatiquement

# 3. Import dans Scalingo
scalingo --app <app-name> domains-add --cert ./certigna-acme.crt --key ./certigna-acme.key <domain>

# OU remplacement d'un certificat existant
scalingo --app <app-name> domains-ssl --cert ./certigna-acme.crt --key ./certigna-acme.key <domain>

# 4. Vérification
scalingo --app <app-name> domains
```

## État

Accepté.

## Conséquences

### Conséquences positives
- **Conformité RGS* maintenue** : Respect des standards gouvernementaux français
- **Protocole ACME adopté** : Automatisation du renouvellement côté Certigna
- **Sécurité renforcée** : Certificats qualifiés reconnus par l'administration française
- **Réduction des risques** : Diminution significative du risque d'expiration
- **Processus modernisé** : Passage du manuel vers l'automatisation ACME
- **Conformité réglementaire** : Maintien de l'éligibilité pour les marchés publics

### Conséquences négatives
- **Coûts maintenus** : Les certificats Certigna restent payants (contrairement à Let's Encrypt)
- **Import semi-manuel** : Nécessité d'importer les certificats dans Scalingo après génération
- **Dépendance double** : Processus dépendant de Certigna ET Scalingo
- **Complexité accrue** : Plus complexe que l'automatisation complète Let's Encrypt

### Conséquences neutres
- **Formation équipe** : Apprentissage du nouveau processus Certigna ACME + import Scalingo
- **Documentation** : Procédures spécifiques à mettre en place
- **Surveillance** : Monitoring des renouvellements Certigna + import dans Scalingo
- **Processus périodique** : Automatisation partielle avec intervention manuelle pour l'import

### Actions immédiates requises
1. **Contact Certigna** : Commander les nouveaux certificats SSL ACME pour nos domaines
2. **Test du processus** : Valider la chaîne complète Certigna ACME → Import Scalingo
3. **Automatisation** : Créer des scripts pour faciliter l'import périodique
4. **Planning de migration** : Migrer domaine par domaine en commençant par le développement

Cette décision nous permet de bénéficier de l'automatisation ACME tout en conservant la conformité RGS* indispensable pour nos applications gouvernementales.
